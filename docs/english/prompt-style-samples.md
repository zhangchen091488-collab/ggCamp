## 推荐提示风格

- 直接写小学生能理解的常用中文义，通常用一个词或短语。
- 去掉 n.、adj. 等词性缩写、英文原形、变形表和无关词典义项。
- 多义词只选择当前学习语境的含义；必要时用短括号限定，例如“长的（说长度）”。
- 单复数需要区分时标注“单数／复数”；不显示英文答案或其原形。
- 短语按短语翻译，不擅自扩成整句；保留原答案、字母格、大小写与标点规则。
- 没有教材原句而无法确定含义的条目进入待核对清单，不自动套用猜测。
