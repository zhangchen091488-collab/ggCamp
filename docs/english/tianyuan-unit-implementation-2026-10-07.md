# 田园外语版与单元学习册交付记录

日期：2026-10-07。已按确认方案完成首期，本次没有 Git 提交、推送或正式发布。

## 使用

设置 → 英语教材 → 田园外语版；英语首页 → 单元学习册。三年级上册包含十个单元、117 个目标（60 个单词、57 条常用语）。学习册支持学校已学标记、词表与学习卡、任意单元或多个单元练习及错题复习。今日练习仅从学校已学范围出题；首次使用田园版需自行标记，未标记时进入学习册。

单元沿用技能书的查看和专项练习体验。英语按词条及题型聚合掌握，不使用数学前置解锁或五星规则。切换教材、调整已学范围不会重置数学、人教词条进度或已有练习快照；替换未完成练习需要确认。

## 内容维护

运行时权威源是 `content/english/tianyuan-g3-first.json`，生成到 `miniprogram/content/`；纯统计模块由 `app/js/english-summary.js` 生成到 shared。单元主题是导航拟定名。

逐条来源见 [来源整理](tianyuan-g3-first-review.md)，机器可读对照见 `tianyuan-g3-first-source-audit.json`。62 条完整句子保留，暂不进入练习。单复数分别入题；重复 sometimes 合并；find places／找路暂不入题，I'm happy／我很兴奋保留为待核对句子。全包仍是 draft/reference-only，未提供音频，朗读、听音默写及独立句子练习不在本期。
