# 瓜瓜计算营：英语学科入口 Spec

状态：已定稿，正在隔离 worktree 实施。2026-10-03 用户改为人教版作为首个试用教材。

## 1. 目标与首版范围

在现有产品首页增加数学／英语入口。英语帮助小学三至四年级学生巩固校内已学单词和常用语，复用瓜瓜伙伴、装扮、收藏、签到、音乐、欢乐值、彩纸和终场庆祝。

首版覆盖微信小程序和 Android APK。网页版本阶段保持数学体验，英语能力通过共享纯逻辑模块为后续网页版接入准备。

首个试用教材改为人教版一年级起点三年级上册，并提供下册可选。用户提供词表尚无单元信息；先做明确标注的整册本地试用，再补教材单元映射和释义审核。沪教版保留为后续可选教材计划。整册试用后，补齐真实单元并完成首个单元的小程序／APK 真机验收，经用户或英语老师校对后再扩展其他册次。

不在首版范围：语音识别、口语评分、自由翻译、长对话、考试测评、登录与跨设备同步、家长端、用户上传任意教材、英语能力自动测评、英语专有新装扮。选择教材不是购买流程。

## 2. 已确认的产品决策

| 项目 | 决策 |

| 读音 | 按册首次联网下载静态读音，缓存完成后离线使用 |

## 3. 用户流程与页面

### 3.1 首页与英语主页

首页显著展示数学与英语入口，伙伴、日历和收藏保持当前风格。首次打开英语进入教材选择；之后记住上次教材、内容类别和默写题型。

英语主页展示当前教材／册次、已学单元、到期复习数及本册掌握数，提供：

- 今日练习：在已学单元范围内复习并加入少量未练内容。
- 单元练习：选择一个或多个单元，自由练习；单元不按掌握强制锁定。
- 错题复习：针对当前教材、当前内容类别及题型的错题。
- 学习卡：查看、学习、重听当前范围内容。
- 切换教材／调整已学单元。

单词和常用语是内容类别，中文提示默写和听音默写是题型；界面分别选择，首版不在一轮中混合类别或题型。

### 3.2 教材选择与准备

按教材系列／版本 → 年级 → 学期选择内容包，显示适用版本、单元数、内容版本、下载体积和缓存状态。首次使用提示选择学校已学到的单元；可以逐单元勾选，后续调整不删除学习记录。

刷新目录可看到新内容包。下载期间显示进度，允许取消、重试；当前已缓存教材始终可用。文本就绪后可中文提示默写；听写必须在本轮所有读音就绪后才开始。

### 3.3 学习卡与默写页

新内容学习卡显示标准英文、中文含义、可选音标、简短语境与读音；学生确认后进入默写。学习卡不是答题提交，不发放练习奖励，不形成掌握证据。

默写页沿用现有「上方伙伴、下方题卡、底部键盘」、全屏背景与组件阴影。英文区域适配长短语及窄屏，按需换行，始终保留可见的提交和提示按钮。

- 中文提示默写：显示明确含义／语境，输入区不预填英文答案。
- 听音默写：进入题目时播放一次英文读音，提供重听；中文释义默认隐藏，查看中文视为提示。
- 应用内键盘支持字母、Shift、空格、撇号、连字符、句末标点、退格、清空和提交；支持移动光标与编辑任意位置。
- 输入途中不判断单个字母、不自动补全、不使用系统拼写建议。
- 空白提交只提示“先写下你的答案”，不记错、不播放失败音效。
- 正确后显示规范答案、反馈和“下一题”；不自动跳走，给学生读答案的时间。
- 错误后保留可编辑输入，显示词级／字符级差异；允许再次提交或点“我还不会”。
- “我还不会”展示规范答案，下一题由学生确认；本题记为未独立正确并进入错题和次日复习。

### 3.4 结算与加时

结算展示首次独立正确率、完成题数、用时、需要复习的内容、本轮学习状态变化、共享奖励及全屏庆祝。将完成分与掌握区分显示，不能用“基础完成分 100”暗示全部掌握。

以实际题数为分母，首次独立正确率 ≥80% 才显示可选加时。首版错题复习模式不进入加时，与当前数学机制一致。

加时只选当前教材、类别和题型中已练过、资源齐备的内容，不临时加入新学习卡。计时 90 秒，暂停／退后台不计时，恢复后由用户点继续；到时停止提交，不追加奖励。计分沿用现有加时曲线，每道首次独立正确题计一个加时得分单位。

## 4. 判题、提示与防重复规则

### 4.1 统一答案标准化

对输入和内容包合法答案执行同一纯函数：Unicode NFC 标准化、大小写折叠、去除首尾空白、将连续空白归一为空格、统一弯／直撇号；只忽略句末的句号、问号、感叹号及对应全角形式。保留内部空格边界、词内撇号和连字符，不做拼写纠错、词形还原或语义推断。

| 内容包标准答案 | 学生输入 | 结果 |
| --- | --- | --- |
| Good morning! | ` good   morning ` | 正确，展示规范写法 |
| can't | `can’t` | 正确 |
| can't | `cant` | 错误 |
| a pencil | `apencil` | 错误 |
| blue | `bleu` | 错误 |
| colour | `color` | 仅当内容包显式列为合法答案时正确 |

单词词形、英美拼写和短语替代表达均由 `acceptedAnswers` 显式配置。中文一词多义时必须提供限定语境，例如颜色“橙色”与水果“橙子”；同中文提示可能合理对应多个英文答案时，由审核者完善提示或配置答案，避免无故判错。

### 4.2 提示与首次独立正确

拼写提示包括首字母、下一字符、显示中文释义（听音默写）、查看完整答案。第一次使用即永久标记本题 `assisted`；关闭弹窗、退后台或改写答案都不能清除此标记。

首次提交正确且未使用提示，才是首次独立正确。正常重听不影响该状态。错误后改正保留鼓励反馈，但不补回本题掌握证据、连击或欢乐值。

同一题的奖励和进度事件只产生一次。重复点击提交、结果页面重入、保存后恢复，不能重复发奖。

### 4.3 已确认的边界参数

- 同一词条／题型在同一天出现错误或使用提示后，当天再次练习可以获得普通答题反馈，但不形成新的跨日独立成功证据；次日可重新取得。
- 查看完整答案后允许跟写一次，也可直接确认下一题；跟写属于学习，不参与加时得分。
- 英语基础轮连击不采用数学逐格倒计时；提交错误、使用提示或“我还不会”打断连击。
- 一轮内同词条不重复；加时题池耗尽可重复出题，但同词条在该轮只计一次加时得分、连击及欢乐值。提前说明“已完成本范围挑战”，允许结束结算。

## 5. 选题与间隔复习

### 5.1 选题规则

计划生成后固定本轮题目、题型、内容包版本和标准答案快照，恢复时不重新抽题。

今日练习按选定单元、类别、题型筛选词条；10 题为 7 复习＋3 新内容，6 题为 4＋2，14 题为 10＋4。优先选择逾期最长的复习项，再按稳定 ID 打破平局。

不足部分依次由剩余到期复习、未练内容、未掌握已练内容、未到期已掌握内容补齐。去重后不足目标题数时按实际数量开始，并显示原因，不通过重复凑数。已学单元减少时，移除的单元退出今日计划，但其记录保留；用户仍可从该单元主动练习。

单元练习在指定单元范围随机抽取不重复内容。错题复习仅选择当前筛选条件下未解决错题；空列表显示“暂时没有错题”及单元练习入口。

### 5.2 进度与复习时钟

记录键为 `packId + itemId + exerciseType`，单词／常用语通过词条类型区分。相同拼写跨册、跨含义不自动合并。

每次首次独立正确推进间隔阶段，分别计划 1、3、7、14、30 天后复习；达到 30 天阶段后保持 30 天间隔。错误、提示后完成或“我还不会”将间隔重置为 1 天。

同一天的成功不重复推进间隔阶段，同一天后续失败可以将下一次复习重置为次日。同轮的修正与跳过不会反复改写多个进度事件。

累计三个不同本地日期的首次独立成功后标记已掌握。已获得掌握标记保留；失败后显示“待巩固”，恢复独立正确后解除待巩固。已掌握不表示无需复习。

本地日期按当前设备日期计算。首版不做时间防作弊；复习日期保留为日期字符串，不因瞬时 UTC 换日让同一轮跨出两个成功日期。轮次开始时固定其学习日期。

## 6. 游戏成长与存档兼容

### 6.1 共享与隔离

| 共享游戏体验／奖励 | 独立学习记录 |
| --- | --- |
| 伙伴、装备、收藏、背景、标记、彩纸、终场、音乐 | 数学技能进度与错题 |
| 每日签到、补签锤、已获得奖杯 | 英语内容包／词条／题型进度与错题 |
| 通用练习次数、练习天数、首次正确题数、欢乐值、通用连击、复习、加时 | 学科历史、未完成轮次、学科及题型统计 |

英语首次独立正确整题等价于一个奖励单位，长词和短词不因字母长度获得不同奖励。完成轮次可推进通用“完成练习”任务；错误后改正不计首次正确任务。历史数学逐数字连击保持原值，新界面注明不同学科计量方式。

数学技能、前置解锁、运算类别、数学年级完成和数字输入数量相关任务／奖杯只收数学事件。现有通用任务明确接收两学科；同一天使用两学科只生成一份日任务、发放一次签到及任务奖励，不因切换重新抽取任务。既有数学专属任务不因英语进度变化而重置。

英语首版可通过通用奖杯解锁已有收藏，不要求新增收藏。通用奖杯文案采用“学习／练习”，数学专属文案明确学科。

### 6.2 存档策略

保留现有存储键和数学字段含义。新增带版本号的英语命名空间，独立保存教材选择、词条进度、错题、历史和未完成轮次；通用奖励通过学科事件汇总，不能把英语词条写进数学 `progress.skills`。

新增通用计量的初始值来自原数学记录，每条新事件按 `sessionId + questionId + eventType` 去重；不得在每次载入时再次累加历史。记录原始学科统计，便于之后查看或重算，奖杯与装备仍使用既有 ID。

每学科最多保留一个未完成轮次。切学科时暂停并保存当前轮次；另一个学科可以继续自己的轮次。开启同学科的新轮次前，明确选择继续旧轮次或放弃。演示、教材切换或结果返回不能覆盖另一学科未完成记录。

保存失败展示可操作提示，不把未持久化状态称为已保存。旧存档首次迁移可重入，数学已获奖杯、装备、历史和未完成题目不丢失；缺少英语字段按空记录初始化。首版跨设备与网页版／小程序记录仍各自独立。

## 7. 教材内容包与远端目录

### 7.1 内容契约

仅允许声明式内容数据与静态音频；内容包不包含脚本、可执行表达式、任意 HTML 或教材专属页面。

| 层级 | 必需字段 |
| --- | --- |
| 目录 | schemaVersion、支持的最低内容能力版本、内容包列表 |
| 内容包 | 稳定 packId、内容 version、seriesId、版本名称、grade、semester、标题、来源与审核信息、单元、词条、资源清单 |
| 单元 | 稳定 unitId、展示名称、排序 |
| 词条 | 稳定 itemId、unitIds、kind(word/phrase)、规范英文、中文含义／语境、acceptedAnswers、audioId |
| 可选字段 | 音标、例句与释义、主题标签、内容说明 |
| 音频资源 | audioId、受信任资源路径、字节数、SHA-256、文件格式 |

内容版本只表示发布修订，不改变 packId。换教材系列或实质不同册次使用新 packId；重排单元、修正排版不重建词条 ID。语义或答案范围实质改变的词条使用新 itemId，历史保留，不强行把旧成功视为新答案掌握。

词条 ID 不由英文拼写临时生成。词条删减后旧记录保留为不再计划的历史；活动轮次使用原快照完成，后续轮次使用新版本。

### 7.2 示例（仅示意，非教材提取）

```json
{
  "schemaVersion": 1,
  "packId": "hujiao-3start-g3-s1",
  "version": "1.0.0",
  "seriesId": "hujiao-3start",
  "grade": 3,
  "semester": "first",
  "units": [{ "unitId": "u01", "title": "示例单元", "order": 1 }],
  "items": [{
    "itemId": "word-001",
    "unitIds": ["u01"],
    "kind": "word",
    "canonical": "blue",
    "promptZh": "蓝色（颜色）",
    "acceptedAnswers": ["blue"],
    "audioId": "voice-001"
  }]

```

示例省略资源清单、审核与来源字段，不能直接当作可发布包。完整 schema、样例包及内容检查器是实施阶段一的交付物。

### 7.3 发布与切换

内容维护者填充标准格式 → 校验 → 用户／老师审核 → 制作并试听读音 → 发布不可变版本文件 → 最后更新目录。目录指向的版本先完整上传，不能让学生下载到半成品。

应用保留最后一次有效目录，刷新失败不清空现有教材。超出客户端支持的 schema／题型标记为需升级，不尝试执行；只填内容即可扩展的承诺限于现有能力。

文本与所选音频按清单下载、校验后原子标记就绪。更新未完成前继续使用上一有效版本，活动轮次不热替换内容。完整下载当前册后，可离线启动两种默写及复习。

缓存页展示各册体积，支持移除下载资源；移除资源不删除掌握与历史。活动轮次占用的资源不能被清理。缓存文件丢失或损坏时重新检查状态并提示下载；网络失败可切到中文提示默写。

缓存以设备允许的持久化容量为边界；V1 工程默认资源预算 50 MiB，单册超预算时不宣布离线就绪，提示清理或缩小下载范围。具体宿主容量需在阶段一真机验证，不能假设小程序和 APK 文件接口完全一致。

HTTPS 资源仅从配置的可信域名下载；校验路径、扩展名、大小、哈希、ID 唯一性和资源引用，拒绝路径穿越、任意远端脚本及超出预算的内容。小程序正式域名配置和 APK 的下载／文件接口验证是上线条件。

## 8. 读音与后台恢复

首版不运行端上或实时云端 TTS，不调用麦克风。发布包提供审核过的录音或可用于计划用途的预生成语音，具体供应者和托管信息作为发布前置资料确定。

选定整册使用一致且经审核的发音口径，语音文件与 acceptedAnswers 对应；句子优先整句读音，不在客户端拼接单词音频。读音清晰、音量一致、无多余开头尾部静音，用户／老师审核。

独立“朗读”播放通道使用缓存文件，保留现有背景音乐／答题反馈通道和 Android 已验证的媒体播放生命周期。朗读期间暂停背景音乐，结束／失败后仅在前台且当前页面仍需音乐时恢复。重听替换当前朗读，不能多路叠播。

教学朗读开关与背景音乐开关分开：关闭游戏音乐不导致听写无声；朗读关闭时禁用听音默写并说明原因。整轮音频就绪后开始，题内播放失败不记为学习错误，保留答案并提供重听／返回准备页。

退后台立即停止朗读并暂停轮次；返回后用户点击继续，听写当前题重新播放一次，输入、提示使用与计时状态不重置。错误、关闭、换页后的旧音频回调不能启动音乐或改写新题。

## 9. 架构与实现边界

当前没有学科插件接口，数学 `cells/steps/digit`、技能前置和数字键盘与数学强绑定。英语不通过修改数学题目生成器来伪装成字符填格。

| 模块 | 职责／复用边界 |
| --- | --- |
| 教材目录与内容校验 | 稳定 ID、版本、合法答案与资源引用；共享纯逻辑 |
| 英语判题 | 标准化、多合法答案、差异反馈；共享纯逻辑 |
| 英语练习计划 | 范围筛选、选词、轮次快照；共享纯逻辑 |
| 英语掌握／复习 | 日期、独立成功、间隔阶段、错题；共享纯逻辑 |
| 学科轮次适配 | 选择学科、暂停恢复、结果事件与存档；平台控制器 |
| 英语页面／键盘 | 小程序与 APK 同套 WXML/WXSS；不改变数学键盘 |
| 内容下载／缓存／朗读 | 平台适配，不假定不同宿主接口相同 |
| 共享游戏成长 | 有学科来源的语义事件、奖励去重、指标筛选 |
| 视觉效果 | 复用现有背景、show-stage、Canvas 庆祝及 DOM+CSS 兜底 |

新增纯逻辑源码放入 `app/js/` 对应英语模块，通过 `tools/build_miniprogram.mjs` 生成 `miniprogram/shared/`；生成文件不手工修改。英文页面和平台媒体／缓存适配放入 `miniprogram/`。

当前 `features.ensureQuests/metrics` 强依赖数学技能，`storage` 会过滤未知数学技能，`file-audio` 路径仅覆盖现有音乐和反馈。这些属于需要新增边界的实现任务，不是已支持英语的接口。

资源目录新增教材时，采用 schema 校验和生成工具即可，无须为教材写分支条件或复制页面。首版不加载远端 UI／逻辑。

## 10. 实施阶段与验收

### 阶段一：内容契约与一个单元

交付：完整 schema、校验工具、一个审核过的试用单元、静态目录样例、规范朗读资源、英语判题及复习纯逻辑测试。

门槛：核对实际教材系列与目录；说明候选词库与发布词库来源；在小程序与 APK 验证下载、持久缓存及缓存文件播放。先解决包体和文件接口事实，再确定真实音频编码和资源上限。

### 阶段二：首版可玩闭环

交付：首页双学科、选册／单元、学习卡、两种默写、自定义键盘、每日／单元／错题练习、结算加时、共享奖励与安全迁移。

门槛：一个单元从首次下载到离线复习可完整运行，数学体验无回归；Canvas 宿主仍走 Canvas，APK 不支持 Canvas 时保持现有 DOM 庆祝。

### 阶段三：整册内容与发布

交付：三年级上册完整词条、常用语、读音和审核记录；帮助说明、缓存管理、断网及后台恢复提示；发布目录与操作说明。

门槛：以下验收矩阵全部完成。后续教材仅走同一内容制作／审核／发布流程；网页版英语另立实施阶段。

### 验收矩阵

| 场景 | 必须满足 |
| --- | --- |
| 正常数学使用 | 旧题库、计分、收藏、日历、后台恢复及未完成练习保持可用 |
| 内容扩展 | 增加第二个样例内容包，不改练习代码／页面，旧应用刷新后能选、下载、练习 |
| 教材切换／更新 | 各册进度保留；稳定 ID 修订不重置；实质新词条不继承；活动轮次版本固定 |
| 判题 | 覆盖大小写、空格、句末标点、弯撇号、连字符、多合法答案、多义提示及空提交 |
| 提示／学习卡 | 重听免费；拼写提示不记独立成功；学习卡和跟写不发练习奖励 |
| 复习 | 6／10／14 配比、题池不足、跨日三次掌握、同日失败、各题型独立、30天上限 |
| 奖励 | 长短词奖励一致；重复提交／重入不重复计奖；英语不解锁数学专有奖杯 |
| 存档 | 新旧／损坏／保存失败场景；两学科各一轮可恢复；演示不污染正式记录 |
| 离线 | 缓存整册后断网完成两题型及复习；损坏文件不误报就绪，缺失读音不无声听写 |
| 网络故障 | 下载中断、取消、更新失败、错误哈希、未知 schema、空间不足可恢复 |
| 音频 | 小程序及重新安装的 APK 各至少三次前后台往返；重听、朗读结束、退出、音乐开关无叠播／卡死 |
| 真机视觉 | 窄屏短句、光标编辑、键盘安全区、全屏背景与庆祝；Canvas 与 DOM 两条路径分别验证 |
| 自动化 | 全部 Node 测试、共享模块一致性、包体门槛通过；新增英文规则测试，不以模拟器代替 APK 真机 |

不以下载量、练习轮数或完成分替代学习成效。试用观察首次独立正确率、到期复习完成率，以及已练词条跨日正确情况；首版使用本地汇总展示，不自动上传学生答案或学习记录。

## 11. 上线前置资料与定稿

资料获取优先利用用户已提供的来源，已有词表不要求用户重复上传。已核实 lilinji/English 的所选三年级上册 XLSX 提供 106 个词条、英美音标及释义，但没有单元字段、完整常用句清单或嵌入音频。

阶段一增加 XLSX 与 qwerty-learner 基础 JSON（`name`、`trans`）的内容整理／导入适配，将其转换成统一内容包；缺失的单元映射、稳定 ID、适龄提示、合法答案和音频清单显式补齐，不能由猜测生成教材单元。导入格式兼容不改变发布词库的来源要求。

用户／英语老师主要核对实际教材版本、单元映射、补充常用语与最终内容审核结果。先由代理整理已有资料并列出具体缺项，再请求无法从来源取得的材料。音频供应者、可用授权、静态资源托管域名及资源发布者在实现阶段一落实。

候选来源核查见 `source-review.md`；已确认决策见 `decisions.md`；术语见根目录 `GLOSSARY.md`。架构决策见 `docs/adr/0001-english-textbook-content-packs.md` 和 `0002-subject-progress-shared-game-growth.md`。

用户已确认完整 spec，包括第4.3节边界参数、题池不足时按实际题数练习、掌握标记保留但失败后待巩固、两学科各保留一轮、缓存预算及朗读／音乐开关分离。资源供应和真机能力仍按阶段一验收，不因定稿而视为已经交付。定稿本身不执行对外发布。

## 12. 开发隔离与数学版本并行迭代

用户要求英语开发使用独立 Git worktree。原数学版本持续迭代，英语代码、生成文件、素材和预览产物均在英语 worktree 中修改，原 checkout 保持用于数学开发。

- 开发分支使用 `codex/english-entry` 或对应英语任务分支，记录创建时的基线提交；worktree 使用独立路径。
- 开始开发时检查并复用合适的英语 worktree；没有时再创建。将本 spec、术语和相关 ADR 同步到开发分支，不能假设主 checkout 的未提交文档自动出现在新 worktree。
- 新增英语模块、页面、题库和测试采用明确的英语目录／命名；共享奖励、存档和音频改动保持最小范围并独立审查，不为接入英语重写数学控制器。
- 共享模块生成、素材压缩、完整测试及小程序预览都以英语 worktree 为工作目录。预览服务使用独立端口，开发工具明确导入英语 worktree 路径；试用记录使用专用测试环境，避免覆盖真实学习存档。
- 合入前同步最新数学基线，解决冲突后重新运行数学及英语测试、共享模块检查、包体门槛和双端关键真机场景；以该基线验证结果为准。
- 英语实现保持在独立分支，不自动提交到数学开发分支或推送覆盖数学发布版本。集成时单独交付可审查的变更与验证结果。

worktree 隔离工作文件，但不会自动消除未来共享代码的冲突。每次修改共享边界都需记录影响及兼容策略，集成前重新确认数学持续迭代后的行为。
